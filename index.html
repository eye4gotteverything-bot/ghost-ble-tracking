            Demo Mode

            Every demo entry is labeled “Demo”, uses fictional names and clearly fictional addresses, and is not a real device. Turning Demo Mode off clears all demo results, flags and demo scan history.

            Distance estimate

            Distance is always an estimate, calculated from signal strength (RSSI) with a path-loss formula. Walls, bodies, pockets and interference can shift it a lot. The environment setting adjusts the path-loss exponent: outdoor 2.0, indoor 2.7, crowded 3.3.

            Updates

            Honest label: in this web version, scan updates appear in the app's Live Updates feed only — a web page cannot message your Muse chat by itself. Chat delivery of live scan updates is a feature of the native Android build, where the app can report scan events back.

            Live scan — what this web version cannot do

            A web page cannot power your phone's Bluetooth or Wi-Fi radios for scanning. Real scanning on all bands — BLE plus 5 GHz and 6 GHz Wi-Fi — requires a native Android build with Bluetooth Scan, location, and Wi-Fi scanning permissions. That native build is the Google Play / APK path. This web version does not and cannot scan real surrounding devices; its only scan data is the fictional Demo Mode.

            Even on a native build, a phone can only see patterns — it cannot prove a device is an IMSI catcher or similar. Targeting flags are awareness aids, not proof.

            Your data

            Everything stays in this browser's local storage on this device. Nothing is sent anywhere, and there is no tracking or analytics. See PRIVACY.md in the repository for the full policy.
